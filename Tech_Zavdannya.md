# Технічне завдання (спрощене)

## 1. Назва проєкту

Система обліку успішності учнів

## 2. Мета

Створити веб-додаток для обліку, аналізу та класифікації успішності учнів замість паперових журналів і розрізнених Excel-таблиць.

## 3. Користувачі

- **Вчитель / класний керівник** - вносить дані, переглядає рейтинги, звіти та рекомендації.

## 4. Функціональні вимоги

1. Додавання, редагування та видалення карток учнів.
2. Внесення, редагування та видалення оцінок за предметами.
3. Пошук учня за іменем/групою; фільтрація оцінок за предметом і семестром.
4. Розрахунок середнього балу учня та рейтингу групи.
5. Класифікація учнів за рівнем успішності та звіт з рекомендаціями для учнів у "зоні ризику".

## 5. Нефункціональні вимоги

1. Відповідь системи - не більше 1 секунди для бази до 1000 записів.
2. Дані зберігаються в базі даних між сеансами роботи.
3. Коректна обробка некоректних вхідних даних без аварійного завершення.
4. Покриття бізнес-логіки unit-тестами - не менше 70%.
5. Основні операції виконуються не більше ніж за 3 дії від головної сторінки.

## 6. Технології

Python, Flask/FastAPI + HTML-шаблони, SQLite, pytest, Git.
