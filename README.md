Навчальний проєкт: додаток для обліку, аналізу та класифікації успішності учнів
## Предметна область

Облік навчальної успішності учнів у школі/класі: ведення карток учнів, предметів
та оцінок, розрахунок середніх балів, рейтингування, та формування звітів для вчителя.

## Технологічний стек

- **Мова:** Python (бізнес-логіка, доступ до даних)
- **Представлення:** HTML-шаблони (Flask/FastAPI)
- **Зберігання даних:** SQLite
- **Тестування:** pytest

## Користувачі (ролі)

| Роль | Потреби в системі |
|---|---|
| **Вчитель / класний керівник** (основний користувач) | Вносить, редагує та видаляє оцінки й дані учнів; шукає та фільтрує записи; переглядає рейтинги, звіти та автоматичні рекомендації по учнях |
| **Учень / батьки** (потенційна роль, розширення в майбутньому) | Перегляд власної успішності та рекомендацій у режимі read-only |

## Функціональні вимоги (скорочено)

1. Додавання, редагування та видалення даних учнів.
2. Додавання, редагування та видалення оцінок за предметами.
3. Пошук учня за іменем або групою.
4. Фільтрація оцінок за предметом і семестром.
5. Розрахунок середнього балу учня та рейтингу групи.
6. Формування звітів про успішність (за групою, предметом, періодом).
7. Автоматична класифікація учнів за рівнем успішності на основі правил.

## Нефункціональні вимоги (скорочено)

1. Відповідь системи — не більше 1 сек. для бази до 1000 записів.
2. Персистентність даних між сеансами роботи.
3. Покриття бізнес-логіки unit-тестами — не менше 70%.
