Навчальний проєкт: додаток для обліку, аналізу та класифікації успішності учнів
## Предметна область

Облік навчальної успішності учнів у школі/класі: ведення карток учнів, предметів
та оцінок, розрахунок середніх балів, рейтингування, та формування звітів для вчителя.

## Технологічний стек

- **Мова:** Python (бізнес-логіка, доступ до даних)
- **Представлення:** HTML-шаблони (Flask/FastAPI)
- **Зберігання даних:** SQLite
- **Тестування:** pytest

## Користувачі

| Роль | Потреби в системі |
|---|---|
| **Вчитель / класний керівник** (основний користувач) | Вносить, редагує та видаляє оцінки й дані учнів; шукає та фільтрує записи; переглядає рейтинги, звіти та автоматичні рекомендації по учнях |
| **Учень / батьки** (потенційна роль, розширення в майбутньому) | Перегляд власної успішності та рекомендацій у режимі read-only |

## Функціональні вимоги
 
1. **Управління даними учнів.** Система повинна дозволяти додавати, редагувати та видаляти картки учнів.
2. **Управління оцінками.** Система повинна дозволяти вносити, редагувати та видаляти оцінки учнів за предметами.
3. **Пошук і фільтрація.** Система повинна забезпечувати пошук учня за іменем/групою та фільтрацію оцінок за предметом і семестром.
4. **Розрахунок успішності.** Система повинна автоматично розраховувати середній бал учня та формувати рейтинг учнів у групі.
5. **Автоматична класифікація та звітність.** Система повинна класифікувати учнів за рівнем успішності і формувати звіт із рекомендаціями для учнів у "зоні ризику".

## Нефункціональні вимоги
 
1. **Продуктивність.** Відповідь системи на запит не повинна перевищувати 1 секунду для бази даних обсягом до 1000 записів.
2. **Персистентність.** Усі дані повинні зберігатись у базі даних і залишатись доступними між сеансами роботи.
3. **Надійність.** Система повинна коректно обробляти некоректні вхідні дані без аварійного завершення роботи.
4. **Тестованість.** Бізнес-логіка повинна бути покрита unit-тестами не менше ніж на 70%.
5. **Зручність використання.** Інтерфейс повинен дозволяти виконати основні операції (додати оцінку, знайти учня) не більше ніж за 3 кліки/дії від головної сторінки.
